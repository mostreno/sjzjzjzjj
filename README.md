# لحظة ميديا | Lahza Media

موقع شركة — وكالة تسويق وحلول رقمية.

## التقنيات
- HTML5
- CSS3 (بدون Tailwind)
- Vanilla JavaScript
- JSON للترجمة والبيانات

## هيكل المشروع
- `index.html` — الصفحة الرئيسية
- `css/` — ملفات التنسيق
- `js/` — ملفات JavaScript
- `data/` — ملفات JSON (ترجمة + بيانات)
- `images/` — الصور واللوجو

## التشغيل محليًا
افتح `index.html` في المتصفح مباشرة.

## النشر
ارفع على أي استضافة تدعم Static Files (Vercel, Netlify, GitHub Pages).
